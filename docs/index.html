⚡ Features

Redstone provides everything you need to build a production-ready Minecraft launcher:

🔐 Secure Account Storage

Refresh tokens encrypted with AES-GCM, key auto-generated per installation.

👤 Multiple Auth Modes

Offline, Microsoft (OAuth2 + Xbox Live), Anonymous guest, Compatibility modes.

☕ Smart Java Runtime

Auto-detection of system/env/custom/embedded Java; fallback download from Mojang, Adoptium, Corretto, Zulu.

📦 Parallel Downloads

Worker pool with retries, SHA1 verification, mirror fallback, and proxy support.

🎨 Modular Asset Loading

Download only what you need: all, textures, sounds, lang, or none.

📚 Library Resolver

Maven path resolution, native classifier per OS/arch, rule-based filtering.

🔄 Full Launch Pipeline

manifest → Java → libraries → assets → client.jar → natives → JVM args → process

🖥️ Window Control

Fullscreen, windowed, borderless, maximized with custom resolution.

🧹 Smart Cache Management

Orphan cleanup, metadata wipe, or keep everything — you choose.

📊 Progress & Events

Typed channels for download progress and stage events.

🪞 Mirror System

Official, third-party, or hybrid chain with deduplication.

🪟 Version Icons

Auto-extract from client.jar, build .ico, create Windows shortcut.

📦 Installation

Add Redstone to your Go project with a single command:

go get github.com/yourusername/redstone/core

Then import it in your code:

import "github.com/yourusername/redstone/core"

🚀 Quick Start

Simple Offline Launch

package main

import (
    "context"
    "fmt"

    "github.com/yourusername/redstone/core"
    "github.com/yourusername/redstone/core/authutil"
)

func main() {
    // Create offline session
    session := &authutil.Session{
        Type:     authutil.AuthOffline,
        Username: "Steve",
    }
    session.Normalize()

    // Launch Minecraft
    launched, err := core.Launch(context.Background(), core.LaunchOptions{
        GameDir:   "./minecraft",
        VersionID: "1.20.1",
        Session:   *session,
    })
    if err != nil {
        panic(err)
    }

    // Stream game logs
    for line := range launched.Process.Logs {
        fmt.Println(line.Text)
    }

    // Wait for game to exit
    launched.Process.Wait()
}

With Progress & Events

package main

import (
    "context"
    "fmt"

    "github.com/yourusername/redstone/core"
    "github.com/yourusername/redstone/core/download"
    "github.com/yourusername/redstone/core/modes"
)

func main() {
    events := make(chan core.StageEvent, 32)
    progress := make(chan download.Progress, 256)

    go func() {
        for e := range events {
            if e.Err != nil {
                fmt.Printf("[%s] ❌ %s: %v\n", e.Stage, e.Message, e.Err)
            } else {
                fmt.Printf("[%s] ✅ %s\n", e.Stage, e.Message)
            }
        }
    }()

    go func() {
        for p := range progress {
            fmt.Printf("\r📦 %d/%d files | %d bytes", p.FilesDone, p.FilesTotal, p.BytesDone)
        }
    }()

    cfg := modes.Default()
    cfg.Java = modes.JavaModeSmart
    cfg.Memory = modes.MemoryModeAuto
    cfg.Download = modes.DownloadModeParallel

    launched, err := core.Launch(context.Background(), core.LaunchOptions{
        GameDir:   "./minecraft",
        VersionID: "1.20.1",
        Session:   session,
        Modes:     cfg,
        Events:    events,
        Progress:  progress,
    })
    if err != nil {
        panic(err)
    }

    launched.Process.Wait()
}

Microsoft Authentication

package main

import (
    "context"

    "github.com/yourusername/redstone/core/accounts"
    "github.com/yourusername/redstone/core/msauth"
)

func main() {
    cfg := &msauth.Config{
        ClientID: "your_azure_client_id",
    }

    // Opens browser for login
    result, err := cfg.LoginInteractive(context.Background())
    if err != nil {
        panic(err)
    }

    // Save refresh token for future use
    store := accounts.NewStore("./minecraft")
    store.SaveRefreshToken(result.Username, result.UUID, result.RefreshToken)

    // Use session for launch
    session := &authutil.Session{
        Type:        authutil.AuthMicrosoft,
        Username:    result.Username,
        UUID:        result.UUID,
        AccessToken: result.AccessToken,
    }
}

👤 Authentication

Redstone supports multiple authentication modes:

Offline Mode

session := &authutil.Session{
    Type:     authutil.AuthOffline,
    Username: "Steve",
}
session.Normalize() // generates UUID and sets default token

Microsoft Authentication

Full OAuth2 + Xbox Live + Minecraft chain with refresh token support:

cfg := &msauth.Config{ClientID: "your_azure_client_id"}

// Interactive login (opens browser)
result, err := cfg.LoginInteractive(context.Background())

// Or use saved refresh token
result, err := cfg.LoginWithRefreshToken(ctx, savedRefreshToken)

Anonymous Guest

session, err := authutil.BuildSession(
    modes.AuthModeAnonymous,
    "",
    gameDir,
    nil,
)

🔄 Launch Pipeline

The launch process follows this exact sequence:

  1. Initialize — Create directory structure
  2. Manifest — Fetch version data from Mojang or cache
  3. Java — Detect, verify, or download Java runtime
  4. Libraries — Resolve and download required libraries
  5. Assets — Download and verify asset files
  6. Client JAR — Download the Minecraft client
  7. Natives — Extract native libraries
  8. Launch — Build JVM arguments and start the process

Each stage emits events through the Events channel for progress tracking.

Core Types

LaunchOptions

type LaunchOptions struct {
    GameDir   string          // Path to .minecraft directory
    VersionID string          // Version ID (e.g., "1.20.1")
    Session   authutil.Session // User session
    Modes     modes.Config    // All configuration modes
    XmxMB     int             // Max memory in MB
    XmsMB     int             // Min memory in MB
    Width     int             // Window width
    Height    int             // Window height
    Events    chan<- StageEvent   // Stage events channel
    Progress  chan<- download.Progress // Download progress
}

StageEvent

type StageEvent struct {
    Stage   string // "init", "manifest", "java", "libraries", "assets", "client", "natives", "launch"
    Message string
    Err     error
}

download.Progress

type Progress struct {
    TaskID       string
    BytesDone    int64
    BytesTotal   int64
    FilesDone    int32
    FilesTotal   int32
    CurrentFile  string
    Err          error
    SkippedCache bool
}

Main Function

func Launch(ctx context.Context, opts LaunchOptions) (*Launched, error)

Launches Minecraft with the given options. Returns a Launched handle or error.

Default Configuration

func modes.Default() modes.Config

Returns a sensible default configuration with JavaModeSmart, MemoryModeAuto, DownloadModeParallel, and more.

cfg := modes.Config{

    Memory:       modes.MemoryModeBalanced,
    Download:     modes.DownloadModeParallel,
    Cache:        modes.CacheModeSmart,
    Network:      modes.NetworkModeAuto,
    Window:       modes.WindowModeBorderless,
    Library:      modes.LibraryModeCurrentOS,
    Asset:        modes.AssetModeMinimal,
    Launch:       modes.LaunchModeNormal,
    Mirror:       modes.MirrorModeAll,
    Log:          modes.LogModeBoth,
}

launched, err := core.Launch(ctx, core.LaunchOptions{
    GameDir:   "./minecraft",
    VersionID: "1.20.1",
    Session:   session,
    Modes:     cfg,
    XmxMB:     4096,
    XmsMB:     1024,
    Width:     1920,
    Height:    1080,
    Events:    events,
    Progress:  progress,
})

Server Mode (No GUI)

cfg := modes.Default()
cfg.Launch = modes.LaunchModeServer

launched, err := core.Launch(ctx, core.LaunchOptions{
    GameDir:   "./minecraft",
    VersionID: "1.20.1",
    Session:   session,
    Modes:     cfg,
})

Fast Launch (Skip Verification)

cfg := modes.Default()
cfg.Launch = modes.LaunchModeFast

// Skips SHA1 checks for faster startup

Test Mode (Dry Run)

cfg := modes.Default()
cfg.Launch = modes.LaunchModeTest

// All checks run, but Java process is not started
launched, err := core.Launch(ctx, ...)
// launched.DryRun == true
